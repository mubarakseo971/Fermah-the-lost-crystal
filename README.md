# The Lost Crystal — Forest Village (Level 2)

A self-contained HTML5 Canvas adventure game for GitHub Pages, designed for desktop and mobile.

## Files
- `index.html` — complete game code, styling, controls, collision, HUD, quest and game states.
- `assets/mascot.png` — transparent-background crop of your supplied blue shark mascot.

## Run locally
Open `index.html` in a modern browser. For best results, keep the `assets` folder next to `index.html`.

## Publish with GitHub Pages
1. Open your existing `the-lost-crystal` repository.
2. Upload/replace `index.html` at the repository root.
3. Upload the `assets` folder and its `mascot.png` file, preserving the folder name.
4. Commit the changes.
5. Go to Settings → Pages → Deploy from a branch; choose `main` and `/ (root)`.
6. Open the Pages URL after deployment finishes.

## Controls and quest
- PC: Arrow keys or WASD.
- Mobile: on-screen directional pad.
- Find all 3 golden village seals, collect optional coins, avoid slimes, and reach the gate.
- The blue villager gives a hint when you approach.

This package is compatible with the earlier single-file starter game, but it is a complete replacement for its `index.html`. It has not been uploaded to or published from your GitHub account.
